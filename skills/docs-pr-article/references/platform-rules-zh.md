# 公众号与小红书的规则对照

这一份记的是**两家规则相反**这件事，因为它最容易让人把稿子投错地方。
作者的原始要求里有「even overclaim it」，那条只对公众号成立。

## 对照

| | 公众号（量子位 / 机器之心 / 新智元） | 小红书 |
|---|---|---|
| 标题长度 | 实测 25 到 40 字，可带副标题 | 20 字以内 |
| `！` 与钩子 | 量子位几乎标配，机器之心不用 | 克制 |
| 夸张标题 | 风格的一部分 | **会压推流** |
| 正文长度 | 长，实测约 59 段 | 每段不超过 3 行 |
| emoji | 基本不用 | 每段 1 到 2 个，列表项各配一个 |
| 结构 | 小标题分节，方法节用编号 | 封面 + 分点 + 标签 |
| 图 | 论文信息图 + 机制图 + 结果截图 | 3:4 竖版封面，6 到 12 页图文 |
| 收尾 | 论文地址 + `— 完 —` | 提问引导评论 + 5 到 10 个标签 |
| 署名 | `量子位 \| 公众号 QbitAI` | 个人口吻 |

## 小红书限流那一条

搜到的运营分析指出，夸大、诱导式标题在小红书不受欢迎，反复使用还可能让推流受限：

> 小红书的笔记标题和公众号的会有差异化，夸大、诱导等标题形式在小红书并不会受到欢迎。

**所以科研内容在小红书要稳妥，`颠覆一切`、`最强`、`狂飙` 这类词反而是负资产。**
同一个结果在公众号可以写成 `准确率狂飙 80%`，在小红书写成 `这个方法把准确率提了 80%`。

## 小红书的格式细节

- **标题**：20 字内，可用数字、疑问句或感叹号，但不夸大
- **emoji 分工**：`📌` 标背景、`💡` 标核心发现、`⚠️` 标局限、`📄` 放文献信息；
  列表用 `1️⃣2️⃣3️⃣` 或 `✅❌⭐`，每项一个
- **排版**：每段不超过 3 行，空行分隔，关键词加粗
- **封面**：3:4 竖版，1 到 2 个核心关键词，颜色对比强，当海报设计；
  纯文字封面适合知识类，可强调时间、速度、数字、方法论
- **结构三段式**：开头用反差或提问，中间分点讲干货，结尾用提问引导互动
- **多图笔记**：6 到 12 页含封面，最后一页是总结或行动呼吁
- **标签**：5 到 10 个，组合是「1 到 2 个泛流量 + 2 到 3 个垂直领域 + 1 到 2 个细分场景」，
  或「2 热门 + 2 长尾 + 1 品牌」。科研向可用 `#科研` `#论文阅读` `#研究生` `#学术干货`
  加上对得上内容的领域标签

## 没查到的
- 小红书对学术账号的外链政策与学术内容推流表现，官方规则未检索到。长期做科研内容应直接查社区规范。
- 三家公众号都没有公开的投稿写作规范或编辑手册，本 skill 的公式全部是从真实标题与正文归纳的，不是官方口径。
